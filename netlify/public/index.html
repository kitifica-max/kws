02

Un comando. Nada de clonar.

Es un plugin real de Claude Code — apunta tu marketplace a este repo una vez, instala por nombre.

claude plugin marketplace add kitifica-max/kws claude plugin install pinterest-design-research@kws

Dentro de una sesión funcionan igual como /plugin marketplace add kitifica-max/kws y /plugin install pinterest-design-research@kws. Ya queda listo para usarse — el skill se activa solo. Sin OAuth, sin API keys y sin cuenta de Pinterest: las credenciales viven solo del lado del servidor.

03

Cómo se usa

No hay comando que memorizar. Dentro de Claude Code, en cualquier proyecto donde esté instalado, basta con pedirlo en texto normal — y cuanto más lo acotes (qué producto, qué tono, qué capas del system necesitas ahora), más preciso sale el brief:

"necesito un design system para un dashboard SaaS fintech: dark, sobrio y enterprise, con tablas y charts — prioriza color, tipografía y estados"

"armá el style guide de mi app de hábitos: mobile-first, cálida y juguetón — layout, componentes y motion con microinteracciones suaves"

"saca los tokens de color y tipografía para una landing de marketplace B2B: tono editorial, cálido, light por defecto"

"¿qué dice el board sobre navegación mobile para una app de finanzas — drawer lateral o bottom tabs?"

Claude reconoce la intención solo — no hace falta nombrarlo. Para forzarlo explícito, también funciona /pinterest-design-research:pinterest-design-research.

En cualquier caso toma las referencias ya guardadas del board — 250+ pines y creciendo — y escribe el brief citado para ese proyecto. No hay board propio que crear ni cuenta de Pinterest que conectar.
