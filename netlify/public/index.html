02

Un comando. Nada de clonar.

Es un plugin real de Claude Code — apunta tu marketplace a este repo una vez, instala por nombre.

claude plugin marketplace add kitifica-max/kws claude plugin install pinterest-design-research@kws

Dentro de una sesión funcionan igual como /plugin marketplace add kitifica-max/kws y /plugin install pinterest-design-research@kws. Ya queda listo para usarse — el skill se activa solo.

03

Cómo se usa

No hay comando que memorizar. Dentro de Claude Code, en cualquier proyecto donde esté instalado, basta con pedirlo en texto normal:

"necesito referencias de UI para un dashboard SaaS tipo fintech"

"ayúdame a armar un style guide para la app de hábitos que estoy construyendo"

"convierte lo que tenemos pineado en design tokens para esta landing"

"¿qué dice el board sobre navegación mobile?"

Claude reconoce la intención solo — no hace falta nombrarlo. Para forzarlo explícito, también funciona /pinterest-design-research:pinterest-design-research.

En cualquier caso toma las referencias ya guardadas del board — 164+ pines y creciendo — y escribe el brief citado para ese proyecto. No hay board propio que crear ni cuenta de Pinterest que conectar.
